# Rasmlar

- `profile.jpg` — profil surati. CV'dagi asl fotosuratdan olingan (to'g'ri
  render qilingan sahifa tasviridan qirqilgan, xom/niqoblanmagan qatlamlar
  ishlatilmagan). Yangi surat bilan almashtirmoqchi bo'lsangiz, shu faylni
  o'z rasmingiz bilan qayta yozing (kvadratga yaqin nisbat tavsiya etiladi,
  chunki profil oynasi kvadrat shaklda ko'rsatiladi).

Boshqa rasm fayllari talab qilinmaydi — "Yutuqlarim" bo'limi endi rasm
o'rniga metrika-markazli kartalardan foydalanadi.
